# GNOME Shell Extensions

## Note about this fork

This is a fork of https://github.com/Darknico/GNOME-Shell-Extensions, however it
adds support for the latest Gnome versions.

I was originally planning to contribute this as a PR back into the original
project, however I realize now that this project has been archived by the
maintainer. This fork should still work if you want to sideload it, however I am
not currently planning to publish this software on the Gnome extension store.
